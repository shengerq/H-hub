# 页面切换和内存优化（2026-10-14）

已修改并完成 Release x64 编译。修改范围：App.cpp、SceneConfigurationPage.inc、PluginCatalogPage.inc。

- 场景页从缓存生成界面，音频和应用数据在后台线程读取；结果回到 UI 线程时核对页面和渲染代数，避免过期响应覆盖新页。
- 插件搜索按实际匹配结果、安装状态及操作状态计算签名。结果没有变化时保留现有卡片和事件；改变时仍正常重建，离页释放。
- 普通切页不强制同步布局；同页重绘需要恢复非零滚动位置时保留布局和恢复逻辑。延迟诊断回调核对页面代数。
- 共享最多 96 种不可变画刷，不缓存整个页面。EQ 布局避免重复写入相同属性。
- 旧页面释放后停止继续请求其应用图标缩略图，图标解码限定 32 像素。

## 同负载测量

隔离、隐藏的 UI 实例各执行 600 次切页（9 个页面）。每次市场页使用 40 项插件数据和 10 次搜索更新请求，两次搜索匹配结果相同，新版可以复用界面。两轮都启用相同布局诊断。第 120 次以后统计：

| UI 私有内存 | 修改前 | 修改后 |
|---|---:|---:|
| 平均 | 60.18 MB | 56.35 MB |
| 峰值 | 65.30 MB | 60.57 MB |
| 旧页面残留最大数量 | 0 | 0 |

没有达到稳定低于 50 MB 的目标。这里记录的是私有提交内存，不等于任务管理器的工作集，也不包含 Core、手机遥控和传感器进程。未清空工作集、隐藏进程或取消必要后台服务。

日志中的 Render ms 不能直接代表端到端切页耗时：旧版本包含同步布局，新版普通切页允许框架随后布局；计时还有 GetTickCount64 的粒度限制。因此不据此宣称帧率或完整切页耗时改善百分比。

测试使用模拟后台，不包含真实插件 WebView、完整真实设备列表和持续可见绘制。实际可见应用是否低于 50 MB 尚未验证。没有操作用户窗口。

结果：navigation-before.csv、navigation-after.csv、navigation-comparison.json。主题回归结果：navigation-theme-check.txt。

补充：移除带目标页面参数启动时先构建首页的行为。--page=scenes 隔离启动日志没有 home 渲染；默认启动只渲染 home；主题与侧栏几何检查通过。该补充没有重新执行 600 次内存测试，以上数据对应此前版本。
