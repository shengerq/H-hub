# 插件库管理

在插件市场标题旁点击设置按钮，进入独立的插件库管理页。每个插件库可以单独命名、编辑、启停和删除；停用或删除库不卸载已经安装的插件。原单库配置会保留。

支持的地址：

- GitHub 的 `owner/repository`、仓库 URL，以及 blob/raw 清单链接。
- Gitee 和 GitLab 仓库 URL；可填写分支与清单路径。GitLab 自托管地址请选择 GitLab 类型。
- HTTPS JSON 清单直链，包括不以 `.json` 结尾的接口地址。
- 本地 JSON 文件的完整路径或 `file:///` 地址；相对插件包路径限定在该清单目录内。

清单沿用 `schemaVersion: 1` 和 `plugins` 数组，插件包仍须提供 SHA-256、ID、作者与版本。远程包允许使用独立的 HTTPS CDN 地址。下载后校验摘要和身份，再由用户审阅权限。

同步仅处理已启用的库；每个库独立保存缓存。失败时使用该库与当前地址匹配的缓存，并在管理页显示原因。不同库中 ID 相同的插件不会静默覆盖；作者冲突阻止更新，相同 ID、作者、版本及摘要的副本在市场合并显示。

随程序附带的 `native-plugin-library` 包含通用 EQ 与手机遥控，可离线显示和安装。两者连接宿主已有原生页面与服务，插件包不包含独立的 DSP 引擎或手机 APK。已安装的原生插件可从市场或插件管理直接打开。

回归检查：`python PluginCatalogTests.py <Hhub.Catalog.exe 路径> [官方插件库 index.json 路径]`。原生包的导入及宿主契约另由核心的 `--self-test` 检查。

EQ 与手机遥控默认不安装。只有已安装的插件显示侧边栏入口；卸载会停止服务、移除登记、清理本插件配置，并撤销手机配对、清理本机证书及属于本程序的防火墙规则。插件升级采用直接替换，保留已有设置。独立安装的共享音频驱动不随插件卸载删除，音频节点会停用并恢复原始路由。

Windows 设置也通过 `Hhub-Windows-Settings-1.0.9.hhub` 安装。未安装时没有侧边栏入口，主程序拒绝 Windows 设置 API；后台只在读取或修改时运行。卸载前等待正在执行的设置操作完成，随后删除插件回退记录和请求文件，不重置用户已应用的 Windows 系统偏好。
