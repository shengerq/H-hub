# EQ 驱动安装与显示名称

本次集成安装包默认安装或修复 EQ 驱动，并将确认属于 ROOT\FXVAD 的设备及标准音频端点显示为 H hub Audio。

INF、SYS、CAT 和许可证保持官方原文件。硬件 ID 与驱动服务不改名；显示名称通过安装后设备和端点属性设置，并回读校验。已有正常驱动时直接复用，不重复创建。无关设备和用户自定义端点名称保持原样。

开关、停止 EQ 及卸载应用只管理 Hhub 自己的处理线程和路由，不移除共享驱动。名称调整由显式安装/修复入口执行。驱动请求重启或音频端点尚待枚举时，安装器会提示重启，日志记录 endpointNamePending。

本轮完成命名范围与驱动复用的 10 项策略检查、官方驱动签名检查，以及配套应用的隔离运行检查；未在当前电脑执行驱动安装或实际改名。
