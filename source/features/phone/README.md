# 手机遥控插件 1.0

本包拥有 WinUI 页面、连接开关、配对码与二维码、HTTPS 后台、证书和授权存储、手机网页、手机状态投影、遥控操作映射，以及设备参数任务适配脚本。

主程序仅通过通用 `pluginInvoke` 调用包声明的能力，按 `lifecycle` 声明启动和清理，并监测或强制停止同一个插件 Job 中的所有进程。插件 DLL 在独立的通用插件宿主内运行，页面嵌入主体内容区；后台子进程继承同一 Job。

手机通过配对和授权后，插件把场景、设备和 EQ 操作转换成声明的 `hostOperations`。主程序只接受已实现且声明允许的原生操作。设备参数任务使用通用 `pluginTaskSubmit/Validate/Ack`；授权、参数范围和回读检查由本插件执行。

`phone-worker.js` 通过通用 `workerExtensions` 扩展设备页面的任务处理，不编译到主程序。主程序中没有手机协议或鼠标参数写入逻辑。

连接设置存于用户数据下 `phone/settings.json`；配对与证书仍保留原有加密文件。卸载清理由包的 `uninstall` 能力执行。最低主程序版本为 1.0，通用接口版本为 1.3。
