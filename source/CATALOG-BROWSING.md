# 市场浏览与第三方插件库

市场将所有已启用来源合并浏览，再按插件类型分为外设和应用。第三方库通过现有的插件库管理页添加，不需要修改主程序或注册新的页面。

## 筛选规则

- 外设依次按类型、品牌、型号筛选；未选择品牌时不展开型号列表。
- 类型变化清空品牌、型号；品牌变化清空型号。所有筛选变化回到第一页。
- 切换外设与应用时清空搜索和筛选，避免跨分类残留条件。
- 应用分类不显示设备类型、品牌和型号控件。
- 搜索忽略大小写，空白分隔的关键词须全部匹配。可搜索名称、型号、品牌、硬件标识、作者、标签和来源名。
- 清除筛选恢复当前大类的全部插件；每页最多 5 个，按窗口剩余高度自动减少，避免上下滚动。市场内容宽度最多 880，超出内容通过分页浏览。

## 第三方索引

沿用 `schemaVersion: 1` 和 `plugins` 数组。基础身份、SHA-256、兼容信息和唯一编码要求见现有插件契约；新增筛选不改变安装和权限审阅流程。

| 字段 | 用途 |
| --- | --- |
| `kind` | 外设使用 `mouse`、`keyboard`、`headset`、`controller` 或 `other`；应用可使用 `application` |
| `group` | 应用声明 `application`；兼容历史值 `applications`。一个索引可以同时提供外设和应用 |
| `brand` | 外设品牌，由第三方提供，不使用内置品牌白名单 |
| `model` | 可选的型号名称；缺少时依次使用 `compatibility.deviceName`、插件名称 |
| `tags` | 补充搜索关键词 |

自定义来源与官方来源使用同一套筛选和包验证流程。完全相同的插件包合并展示并保留来源名；作者不同的同 ID 插件不能覆盖已安装包。

本地目录导入兼容 `外设插件/类型/品牌/包.hhub` 和 `类型/品牌/包.hhub`。`资料源码` 是过时插件归档，不参与递归扫描或市场索引生成。

## 验证

`CatalogBrowseTests.vcxproj` 针对同步结果检查分类隔离、品牌型号联动、多关键词和硬件标识搜索。现有隔离 UI 测试开关 `HHUB_CATALOG_INTERACTION_TEST=1` 可检查实际控件交互，必须同时使用 `HHUB_TEST_PROFILE=ui-memory-tests` 和隔离模型数据。
