H hub 1.0 R6 修复 EQ 绘制、深色侧栏和传感器授权重试问题。

- 修复 EQ 页面黑块、重复绘制闪烁以及侧栏启动时的主题显示。
- 主页和系统监测页增加“授权读取传感器”入口，显示授权等待与失败提示，支持采集停止后重新授权。
- 最小化、离开监测页或关闭界面时释放传感器采集程序；取消授权后不会反复弹窗。
- 保留 Windows 设置、EQ、手机遥控集成功能，以及 EQ 驱动安装与 H hub Audio 改名。

已通过实际安装版的九项授权状态检查（模拟状态）和九项生命周期检查，并核对 374 个安装文件。内存未确认有明显下降；实体机 CPU 温度、频率、功耗和实际音频效果仍需相应硬件验证。已有 1.0 用户需手动下载安装本次修订版。
