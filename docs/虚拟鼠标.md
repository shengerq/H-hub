# 用正式插件连接虚拟鼠标

虚拟鼠标是 H hub 原生 HID v2 的一个设备后端。插件使用与物理设备完全相同的 `.hhub` 文件、驱动编解码和页面，通过宿主读写虚拟设备。不需要体验插件。

目前仅提供 VAXEE XE Wireless（3057:1003）与 MCHOSE A7 V2 Ultra+ 接收器（3837:100B）两种虚拟设备。其他协议：没有模拟器。实机验证：没有。

先构建主程序。在独立目录启动进程时设置以下环境变量；不要在正常使用配置中设置它们：

```powershell
$env:HHUB_TEST_PROFILE='mouse-per-device-tests'
$env:HHUB_VIRTUAL_MOUSE='1'
$env:LOCALAPPDATA='C:\HhubVirtualMouseData'
```

将 LOCALAPPDATA 换成专门的数据目录；两个进程 Hhub.exe、Hhub.Core.exe 必须使用相同环境。该后端只有在独立鼠标测试配置中才启用；关闭环境开关后仍使用正常物理 HID 后端。

从 [H-hub-plugins 品牌文件夹](https://github.com/shengerq/H-hub-plugins/tree/main/catalog/peripherals/mouse) 导入对应正式包，然后在插件管理打开设备插件，点击“连接设备”。VAXEE 支持 DPI、回报率；MCHOSE 还可体验 Motion Sync、角度修正和波纹修正。页面会标明虚拟设备。

后端未安装系统级虚拟 USB 驱动，不会让 Windows 设备管理器多出鼠标。虚拟设备模式下 HID v2 事务只路由到软件后端；列入宿主设备清单时明确 `real:false`、`virtual:true`。

软件验证包括正式包经原生 Core IPC 的 11 项读写检查。中文路径黑屏来自本地文件 URL 的中文与百分号编码差异，已通过 PluginDocumentUri 的路径编码回归测试修复；最终窗口验收仍需实际打开确认。模拟结果不能作为硬件验收证据。
