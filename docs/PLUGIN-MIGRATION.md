# 插件代码边界（2026-10-19）

主程序只提供 WebView 页面容器、主题数据、配置/场景数据桥、声明授权的 HID 收发和运行监测。`ui.profileAdapterVersion=1` 明确声明配置接口，主程序不再通过搜索插件源码判断型号或注入适配代码。

VT3S MAX 的协议、配置捕获/应用/回读、远程参数映射、页面样式和 PNG 均位于外设库的 `鼠标/Rapoo/VT3S-MAX`，可独立重建 0.5.3 插件。其他在用离线插件和开发者工具也携带自身显示样式；旧包放入相应库的资料源码。

HID 描述符缺少 Feature 长度时，宿主使用插件 `hidV2Targets[].implicitFeatureLength` 声明并检查 1–4097 整数字节范围，不含厂商/产品 ID 例外。插件权限、实际报告 ID 以及负载长度检查仍生效。

VAXEE/MCHOSE 虚拟设备协议只保留在外设库开发测试资料中；正式构建不包含模拟协议。运行环境变量不能在正式版开启它。专用测试项目必须显式传入 `VirtualMouseFixtureHeader` 外部测试头文件路径。

同步更新主程序和插件。旧 VT3 包依赖已移除的宿主注入，不属于本版支持组合。本次软件回归不等于有线、2.4G、混合连接的实机验收。
