H hub 1.0 R3 将三项常用功能集成回旧版，并改善页面资源回收与覆盖安装体验。

- 内置 Windows 设置、EQ 和手机遥控，手机遥控保留左侧二维码、右侧详细信息布局。
- 外设控制交由插件，三项内置功能页面共用主界面。
- 市场分页固定在底部，按钮文字居中，页面不整体上下滚动。
- 传感器列表按需创建控件，离开监测页、最小化或关闭界面时停止辅助采集。
- 覆盖安装保留配置并更新入口；卸载新增保留插件和个人数据的选项，默认保留。
- 安装包提供 EQ 驱动安装/修复及 H hub Audio 显示名称设置。
